# Privacy Policy

**Last updated: 18 September 2026**

This private TikTok analytics connector is maintained by Eduard Epshteyn.

## Data accessed
After OAuth authorization, the connector may read the authorized TikTok profile and public video metadata and counters, including views, likes, comments, shares, follower count, and video count when TikTok makes those fields available.

## Data storage
The connector stores OAuth tokens locally in a protected environment file used by the private MCP process. Analytics responses are returned to the authorized user's AI workflow. The service does not sell data or use it for advertising.

## Sharing
Data is not shared with third parties except requests made to TikTok's official API and the user's selected AI client.

## Retention and deletion
You can revoke TikTok authorization and delete the local token file at any time. Cached analytics data can be deleted from the local project or client storage.
